This step-by-step guide covers installing,configuring and testing the Lenco Payment Gateway Dev By Simnko Module for WHMCS.
Before setting up the module, make sure you have:WHMCS Installation: WHMCS v8.x or later.Lenco Account: An active account with Lenco.API Credentials: Your Lenco Public Key and Secret Key (available in your Lenco Merchant Dashboard under Settings > API & Webhooks).the Module: Get the lenco WHMCS payment gateway files (typically provided as a .zip archive from Github or call simnko on 0973215564 for help cause this is the custom module dev by simnko).Extract Files: Unzip the folder on your local machine.
Upload to Server: Upload the extracted files into your WHMCS root folder:File path: your-whmcs-directory/modules/gateways/3.Activating the Gateway in WHMCSLog in to your WHMCS Admin Area.Navigate to System Settings (gear icon) > Payment Gateways (or Setup > Payments > Payment Gateways in older versions).Click on the All Payment Gateways tab.Locate Lenco and click it to activate the module.4. Configuring Gateway SettingsAfter activating, you will be taken to the Lenco Gateway Configuration page (or find it under the Manage Existing Gateways tab):Setting FieldDescription/Recommended ValueShow on Order FormCheck this box to enable Lenco at checkout.Display NamePay with Lenco (Card / Bank Transfer)Public KeyEnter your Lenco Live Public Key.Secret KeyEnter your Lenco Live Secret Key.Sandbox / Test ModeCheck to enable testing mode (use Sandbox API Keys).Convert to For Processing Select your primary store currency (e.g. ZMW, USD) if accepting multiple currencies.Click Save Changes when finished.5. Configuring Webhooks (Instant Payment Notifications)To ensure WHMCS automatically marks invoices as Paid upon successful transaction, set up the callback webhook in your Lenco Dashboard:Log in to your Lenco Merchant Dashboard.Go to Settings > API & Webhooks.Set your Webhook Notification URL to https://your-domain.com/whmcs/modules/gateways/callback/lenco.php
.Save the webhook settings.6. Testing the IntegrationEnable Test Mode: Ensure Sandbox / Test Mode is checked in your WHMCS Lenco Gateway settings.Create a Test Invoice: Log into your WHMCS Client Area, generate a test order or open an unpaid invoice.Checkout: Select Lenco as the payment method and click Pay Now.Complete Payment: Use your phone number to complete the transaction.Verify: Ensure the invoice status changes to Paid and a transaction ID is logged under Transactions in WHMCS.
